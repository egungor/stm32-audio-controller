# Images

Board photos and LCD screenshots used by the documentation and the project
presentation live here.

## LCD screenshots of the UI

When the screen design is settled (M2), add a screenshot of each screen as
it appears on the LCD, and add them to the project presentation in place of
the draft UI drawings.

- Prefer an exact capture of the framebuffer over a phone photo: dump the
  framebuffer over SWD and convert it with `tools/fb2png.py`
  (see `docs/toolchain.md`).
- Use descriptive lowercase names, e.g. `ui-main-screen.png`,
  `ui-waiting-for-host.png`, `ui-volume.png`.
- Record the firmware commit the screenshot was taken from in the commit
  message.

The presentation is a claude.ai artifact owned by the project developer:
<https://claude.ai/artifact/1iZGqWiF55fRbjfhNWXViQ>
